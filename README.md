# Puzzle 50 piezas — GitHub Pages

## Corrección importante
La imagen `foto-puzzle.jpg` está ahora **en la misma carpeta que `index.html`**. Esto evita problemas habituales de rutas al publicar en GitHub Pages.

La estructura debe quedar exactamente así:

```text
/
├── index.html
├── style.css
├── foto-puzzle.jpg
└── README.md
```

No cambies el nombre `foto-puzzle.jpg`.

## Publicación
En GitHub:
**Settings → Pages → Deploy from a branch → main → /(root)**.

Después de subir los archivos, espera a que termine el despliegue y abre la URL de GitHub Pages.

Si ya tenías una versión anterior, reemplaza `index.html`, `style.css` y `foto-puzzle.jpg` por estos archivos.
